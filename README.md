## ¿Qué es PDFJM?

PDFJM es una aplicación para visualizar, editar, organizar, convertir y gestionar documentos PDF mediante una interfaz intuitiva y completamente en español.

El proyecto forma parte de **Tecnología útil con Jhon Monsalve**, una iniciativa dedicada al desarrollo de herramientas digitales gratuitas para la vida diaria, la docencia y la investigación.

PDFJM dispone de una versión web y una edición de escritorio diseñada para funcionar sin conexión a Internet.

## Funcionalidades principales

- **Edición:** agregar textos, imágenes, firmas manuscritas y anotaciones.
- **Resaltado:** resaltar, subrayar y dibujar sobre documentos.
- **Organización:** insertar, eliminar, girar, extraer, reemplazar y reorganizar páginas.
- **Combinación:** unir documentos PDF.
- **Conversión:** transformar imágenes en PDF y exportar páginas a PNG o JPG.
- **Formularios:** completar campos interactivos directamente sobre el documento.
- **Reconocimiento de texto (OCR):** reconocer y extraer texto de documentos escaneados.
- **Personalización:** incorporar numeración, encabezados, pies de página y marcas de agua.
- **Exportación:** guardar los documentos modificados.

## Versiones para Windows

### PDFJM — Instalador

Archivo: `PDFJM-Instalador-0.7.2-x64.exe`

Permite instalar PDFJM en Windows como una aplicación independiente.

### PDFJM — Portable

Archivo: `PDFJM-0.7.2-Portable.exe`

Permite ejecutar PDFJM sin realizar una instalación convencional.

Ambas modalidades están diseñadas para funcionar sin conexión a Internet.
